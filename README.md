# BookBazaar

BookBazaar is a **dynamic PHP-based bookstore web application** that lets users browse, search, and manage books with a clean, responsive UI.  
It includes **customer, admin, and delivery roles**, a lightweight **JSON-based backend**, and smooth client-side interactivity via JavaScript.

---

## Features

### User Side
- **Browse & Search Books** — Search by title, author, or genre with smart filters and sorting.  
- **View Book Details** — See descriptions, prices, authors, and genres with a uniform layout.  
- **Add to Cart / Wishlist** — Save or purchase books; cart data handled dynamically.  
- **Submit Reviews** — Leave ratings and comments; reviews are stored persistently in JSON.  
- **Responsive Design** — Works seamlessly across desktop, tablet, and mobile.

### Admin Panel
- **Manage Books** — Add, edit, or delete books through clean PHP forms.  
- **View Orders** — Track customer orders and statuses in real-time.  
- **Role-Based Navbar** — Admin sees management options; users see shopping features.

### Delivery Panel
- **View & Update Orders** — Delivery staff can update delivery status.  
- **Simple Dashboard** — Lightweight and easy to navigate.

## Tech Stack

| Layer | Technology |
|--------|-------------|
| **Frontend** | HTML5, CSS3 (custom responsive + pastel theme), JavaScript |
| **Backend** | PHP 8 |
| **Data Storage** | JSON files (`books.json`, `users.json`, `reviews.json`, `orders.json`) |
| **Server** | Apache (XAMPP) |
| **Version Control** | Git & GitHub |
